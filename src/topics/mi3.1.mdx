Before a firm can decide how much to sell, it has to know how its output changes as it adds workers. The production function describes that link, and diminishing marginal returns explain the shape of almost every cost curve that follows.

## Short run and long run

In the **short run**, at least one input is fixed, usually the size of the plant or the number of machines. In the **long run**, every input can be changed. The line between them is not a number of months; it depends on how long it takes the firm to change its fixed inputs.

## Total, marginal, and average product

- **Total product (TP):** total output at each number of workers.
- **Marginal product of labor (MPL):** the extra output from one more worker. MP = ΔTP ÷ ΔL.
- **Average product of labor (APL):** output per worker. AP = TP ÷ L.

## Diminishing marginal returns

With a fixed amount of capital, adding workers eventually makes each new worker less productive. The first few workers may raise output a lot, since they can specialize. After some point, workers start crowding the same machines and space, and **marginal product falls**. That is the **law of diminishing marginal returns**. It is a short-run idea, because it depends on one input being fixed.

Three stages show up in a TP curve:

- **Increasing marginal returns:** MP rises. TP gets steeper.
- **Diminishing marginal returns:** MP falls but stays positive. TP still rises, more slowly.
- **Negative marginal returns:** MP is below zero. TP falls. No sensible firm hires this many workers.

## How MP and AP relate

When MP is above AP, AP rises. When MP is below AP, AP falls. So **MP crosses AP at the highest point of AP**. It works like grades: a new test score above your average pulls the average up.

## On the exam

- Calculate MP and AP from a table.
- Identify where diminishing marginal returns begin.
- Explain that diminishing returns happen because another input is fixed.
- Link to costs: falling MP means rising marginal cost (Topic 3.2).

<Callout kind="mistake">
Saying diminishing returns start when total product begins to fall. They start earlier, when marginal product starts to fall. Total product keeps rising until marginal product turns negative.
</Callout>
