This topic turns the hiring rule into numbers. Expect a table of workers and output, a product price, and a wage, and be ready to find the profit-maximizing number of workers.

## The hiring rule

A profit-maximizing firm hires workers until **MRP = MFC**. In a perfectly competitive labor market, MFC is the wage, so the rule is **MRP = wage**.

- If MRP > wage, the next worker adds more revenue than cost, so hire.
- If MRP < wage, the last worker cost more than they brought in, so hire fewer.

With whole workers, hire every worker whose MRP is at least the wage, and stop before the first one whose MRP is below it.

## The firm and the market

In a competitive labor market, the market wage is set by market labor supply and demand. Each firm is a **wage taker**: it faces a horizontal labor supply curve at that wage, where MFC = wage. The firm then picks how many to hire by comparing MRP with that wage. Like the competitive firm in Unit 3, this is best shown with side-by-side graphs.

## Using more than one input

When a firm uses labor (L) and capital (K):

- **Least-cost rule:** MPL ÷ PL = MPK ÷ PK. The last dollar spent on each input adds the same output. If one side is larger, the firm should shift spending toward that input.
- **Profit-maximizing rule:** MRPL = PL and MRPK = PK, so MRPL ÷ PL = MRPK ÷ PK = 1.

A firm can be using the least-cost combination and still be hiring the wrong total amount. Profit maximization requires both ratios to equal 1.

## On the exam

- Compute MP, MRP, and the profit-maximizing number of workers.
- Apply the least-cost rule to decide whether to use more labor or more capital.
- Show a change in the wage or product price and the new hiring decision.

<Callout kind="mistake">
Comparing marginal product (in units) with the wage (in dollars). Convert to dollars first: MRP = MP × price, then compare with the wage.
</Callout>
